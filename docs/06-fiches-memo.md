# 6. Fiches mémo (à imprimer près de la caisse)

## Fiche CAISSE

**Ouvrir** : touchez votre prénom → tapez votre code.
**Partir** : Plus → **Verrouiller** (ou le cadenas sur l'ordinateur).

**Faire une vente**
1. Touchez le gros bouton vert **Vendre**.
2. Cherchez le produit (« ciment », « fer 10 ») ou touchez-le dans « Les plus vendus ».
3. Touchez la quantité (5, 10, 20…) ou tapez-la → **Ajouter**.
4. Le client négocie ? Touchez **Prix** et tapez le prix accordé.
5. Répétez pour chaque article → **Encaisser**.
6. Choisissez **Espèces**, **MTN MoMo**, **Moov Money** ou **À crédit**.
7. Espèces : tapez ce que le client donne. La **monnaie à rendre** s'affiche.
8. **Valider la vente** → **Ticket** ou **WhatsApp**.

**Vente à crédit** : « À crédit » → choisissez le client (ou « Nouveau client ») → tapez l'avance s'il en donne une → Valider.

**Un client rembourse** : Clients → son nom → **Il paie maintenant** → montant → Enregistrer.

**Un client rapporte un article** : Ventes du jour → la vente → **Retour d'articles**. L'application dit s'il faut rendre de l'argent.

**Le soir** : Ventes du jour → **Point de caisse**. Le montant « Espèces » doit être dans le tiroir.

## Fiche VENDEUR / MAGASIN

**Trouver un produit** : Accueil → **Trouver un produit** → tapez le nom. La couleur indique la zone :
🟧 Hall · 🟦 Magasin principal · ⬛ Ciment · 🟪 Carrelage · 🟫 Matériaux · 🟥 Arrière-cour.
Le **Plan** montre la zone et l'étagère en surbrillance.

**Déplacer un produit** : fiche du produit → **Déplacer** → vers quelle zone → quantité.

**Compter (inventaire)** : Inventaire → touchez la zone → pour chaque produit :
- le chiffre est juste → **C'est juste** ;
- il est faux → **Autre**, puis tapez ce que vous voyez.
Vous pouvez arrêter et reprendre plus tard : tout est enregistré.

## Fiche RESPONSABLE

**Chaque matin** : Accueil → ventes d'hier, liste **À commander**, **Les clients me doivent**.
**Livraison d'un fournisseur** : **Réception marchandise** → fournisseur → produits livrés et prix → Valider. Le stock augmente tout seul.
**Nouveau produit** : Stock → **+ Produit**.
**Un chiffre de stock est faux** : fiche du produit → **Corriger** → quantité réelle + explication.
**Valider un inventaire** : Inventaire → la zone comptée → **Terminer et corriger le stock**.
**Relancer un client** : Clients → son nom → **Rappel poli par WhatsApp**.
**Ajouter un employé / changer un code** : Paramètres → Équipe.
**Chaque mois** : Paramètres → **Télécharger une sauvegarde** → envoyez-la sur votre WhatsApp. Puis **Rapports** → « Ce mois ».

**Pas d'Internet ?** Continuez normalement. Tout partira tout seul quand le réseau reviendra.
